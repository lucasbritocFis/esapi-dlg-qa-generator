
# Documentation

This folder contains supplementary documentation and assets for the DLG QA Plan Generator.

## Contents

- `img/` — Screenshots, diagrams, and animations used in the main README
- `diagram.py` — Python script that generates the field geometry diagram
- `animate.py` — Python script that generates the animated sweep GIF

## Regenerating assets

Both Python scripts run in Google Colab without any local installation. See the inline comments in each script for details.
